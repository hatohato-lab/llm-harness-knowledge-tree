# llm-harness-knowledge-tree — LLM の扱い方の知識の木

A classified knowledge tree about working with LLM agents such as Claude Code, written in Japanese. It covers how to instruct them, manage their context, split work, evaluate results, and keep them safe. Each of the 326 leaves explains one technique: why it works, how to try it, and how well the evidence holds (official docs, papers, original sources, or anecdotes only). Most of the text was written with AI assistance. See the limitations section.

## 1. この木とは（何を分類したものか）

LLM（Claude Code などのエージェント）の扱い方を、6つの枝と326枚の葉に分類した、日本語の知識の木です。
1枚の葉は、1つの型（手法や考え方）を扱います。
目的は、指示文を集めて自動で回すことではありません。
仕組みをいろいろな型で理解し、扱いに慣れるために作りました。
材料は、2026年8月から10月に X で見つけた Claude Code の投稿（このリポジトリには載せていません）、公式の文書、論文です。

## 3. 葉の読み方（7つの節と、根拠の段階7種）

葉は、次の7つの節でそろえてあります。

1. 要点：一言、根拠の段階、使いどころ（モデル、指示、作業）
2. 仕組み：なぜ効くか
3. 使い方：手順と例
4. 試し方：最初の一歩と、うまくいったかの測り方
5. 出典：公式の文書や論文の URL、確認の限界
6. 試した記録：私が試した結果（どの葉も、まだ試していません）
7. 関連：ほかの葉へのリンク

**根拠の段階7種と、この木での意味**

| 根拠の段階 | この木での意味 | 葉の数 |
|---|---|---|
| 本体と公式で確認 | 公式の文書と、Claude Code の本体の設定や動きの両方で確かめました | 5 |
| 公式で確認 | 公式の文書で確かめました | 226 |
| 論文で確認 | 論文の報告で確かめました | 53 |
| 元の出典で確認 | 投稿が元にした出典（記事やリポジトリなど）で確かめました | 39 |

| 誤りの疑い | 主張に誤りの疑いがあります | 0 |

## 4. 木の作り方（調べて分類し、採点して直す）

1. 調べる：X の Claude Code の投稿を API で集め（約1,200件）、使い方の型を取り出しました。
2. 根拠をたどる：型ごとに、投稿のリンク先、公式の文書、論文、Claude Code の本体の設定の定義まで、根拠をたどりました。
3. 分類する：型を326枚の葉に分け、6つの枝に整理しました。
4. 採点して直す：葉の形を機械で採点する道具（tools/check_leaves.py）と、中身を読む採点を回し、枝ごとに修正と再採点をくり返しました。

中身を読む採点は、次の4つを確かめました。

- 仕組みに、なぜ効くかが出典つきで書かれていること。
- 使いどころが、モデル、指示、作業で具体的に書かれていること。
- 試し方の最初の一歩が1時間以内にでき、数で確かめられること。
- 出典の道筋が、リンクでたどれること。

## 5. 著作権と出典（本文を写さず、出典へリンクする）

- 葉の文章は、調べた内容を私の言葉で書き直したものです。
- X の投稿は、本文、反応の数、投稿者名、URL（投稿 ID）のいずれも載せていません。X の開発者向けの方針が、投稿の再配布に条件を付けているためです。
- 公式の文書、論文、記事は、題名と URL を載せ、内容は要約しています。
- 引用が要る場合は、短い語句に限り、出典を付けています。
- 5節（出典）は、公開向けに要約した形です。調べたときの詳しい確認の経過は、公開していません。
- 権利の問題に気づいたときは、Issues で知らせてください。確認して、必要なら取り下げます。
