## 1. 要点（一言と、根拠の段階と、使いどころ）

調べる深さと、読ませる説明の長さを別々に指定します。

- 根拠の段階：公式で確認
- 推論量を設定できるモデルでは、検討の深さと回答の文数を別々に指定します。
- 軽量の文章生成モデルでは、結論・根拠・例外の順と短い完成例を添えます。
- 使いどころ：短い報告、学習用の解説、レビューの報告。

設定例を公式で確認できるのはClaudeの推論対応モデルです。
軽量モデルへの使い分けは、この葉の検証案です。

推論量は、モデルが考える深さや頻度の目安です。
説明粒度は、読み手へどこまで詳しく説明するかです。
両者の指定は、同じ意味ではありません。

## 2. 仕組み（なぜ効くか）

[公式の推論量の説明](https://platform.claude.com/docs/en/build-with-claude/thinking-steering-and-cost#effort-levels)では、
effortは考える頻度と深さを調整する目安です。
[回答の長さの説明](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices#communication-style-and-verbosity)では、
Claude Opus 5の表示の長さはeffortだけでは安定して変わらず、
簡潔さを指示するよう案内しています。
そのため、検討条件と出力条件を分けると、別の調整対象を混同せずに済みます。
「結論・根拠・例外を残す」は、この原則から組み立てた指示案です。
必要な情報の脱落を減らせるかは、第4節で測ります。

[Claude Codeの出力スタイル](https://code.claude.com/docs/en/output-styles)にも、
作業は十分に行い、報告を短くするConciseがあります。
Explanatoryは理由の解説を加え、Learningは利用者が書く部分も設けます。
これらは公式の機能説明で、理解度の改善幅の実測ではありません。

図解も、説明の量を選ぶ一つの手段です。
関係が見たいなら図、手順が見たいなら順序を指定します。
図の美しさと、内容の正しさは別に確かめます。

## 3. 使い方（手順と例）

1. 読後に何を判断したいか決めます。
2. 残す情報を、結論、根拠、例外に分けます。
3. 回答の文数と説明順を指定します。
4. 詳しい検討が必要なら、その条件を別に書きます。

短い報告の例です。

```text
二つの案を、要件と資料に照らして検討してください。
回答は結論1文、根拠3点、未確認事項1点の順にします。
資料で確かめた範囲も書いてください。
短い回答のために、必要な照合は省略しないでください。
```

学習用の例です。

```text
入力から結果までの関係を、小さな図で示してください。
その後、各段階を1文ずつ説明してください。
専門用語は、登場前に1行で説明してください。
最後に、私が理解を確かめる問いを一つ出してください。
```

点検の範囲と報告件数も分けます。
「全変更を点検し、重要な指摘を最大3件報告」と書けます。
重大な問題が残るなら、その件数と未掲載を明記させます。
件数に合わせた指摘の水増しは求めません。
[i-have-adhdの指示本文](https://github.com/ayghri/i-have-adhd/blob/main/skills/i-have-adhd/SKILL.md)の第9項にも、
表示する件数の制限で分析・検索・保持する情報を狭めない指定があります。
この例は指示の書き方であり、効果を測った結果ではありません。

## 4. 試し方（最初の一歩と測り方）

最初の試行は、準備・比較・採点を合わせて50分の計画です。
使えるモデルが設定済みで、短い公開資料がある状態から始めます。

1. 10分で600〜1,000字の資料を1件選び、必須事実5個を採点表に書きます。
   5個には、結論・根拠・例外または不確かさを含めます。
2. 15分で同じ資料を使い、通常版1件と短縮版1件を別の会話で作ります。
   モデル・推論量・残す5事実は固定し、出力長だけを変えます。
   通常版は600字以内、短縮版は300字以内とします。
3. 15分で先に読む版をくじで決め、両版の読了秒数を測ります。
   文字数と事実の保持数も数え、読んだ順序とともに記録します。
   事実は資料と照合し、正しく残れば1点、欠落・誤りなら0点です。
4. 10分で結果を比べ、消えた例外と追加質問数も記録します。

この試行の合格条件は、短縮版が5/5点を保ち、追加質問0件で、
読了時間が通常版の80%以下になることです。
時間切れや必要事実の欠落は未達とします。
50分と80%はこの葉の仮の基準で、一般的な最適値ではありません。
同じ人が続けて読むため、先に読んだ内容を覚える影響は残ります。
1件だけでは効果を一般化できません。今回は実施していません。
