## 1. 要点（一言と、根拠の段階と、使いどころ）

**一言：複数の判定を保存し、食い違う理由から採点の弱点を探す。**

根拠の段階：公式で確認。

モデル：推論型・高性能な汎用言語モデルを採点役の一つにし、軽量な汎用モデルとの違いも調べる。
採点役を分けても、同じ誤りが重ならないとは限らない。
同じモデルを複数回使う場合も、誤りを共有しうる。
指示：同じ基準と出力欄を、具体的に与える。
作業：曖昧な文章評価や、重要な採否の再確認に向く。

## 2. 仕組み（なぜ効くか）

複数採点は、同じ成果を複数の採点役で評価する方法である。
公式記事は、複数の判定を合わせる方式を挙げる。[1]

以下は、不一致を学ぶための実務案である。
先に別々に採点すると、異なる読み違いを見つけられる。
多数決が正しいとは限らず、同じ誤解が重なる場合もある。
採点役の数だけで、結論の確かさを決めない。

## 3. 使い方（手順と例）

1. 同じ成果と基準を、採点役ごとに渡す。
2. 他の採点役の答えを見る前に、結果を確定する。
3. 合否、証拠の箇所、不明点を並べる。
4. 不一致の項目を、原資料か人の判断へ戻す。
5. 採否の規則を適用し、各判定も保存する。

例：二つの採点役で、出典の裏付けだけが割れた。
平均点で消さず、出典の該当箇所を読み直す。
同意見でも、重要な条件は規則採点や人で確認する。

## 4. 試し方（最初の一歩と測り方）

最初は50分で、根拠資料の付いた短い文章5件を二つの採点役で評価する。
以下の時間・件数・成功基準は、この葉の学習用の提案であり、研究の実測値ではない。

1. 10分で5件を選び、「主張を出典が支えるか」の合否基準を固定する。
2. 10分で人が5件の合否と根拠を先に書き、モデルの結果を見るまで変更しない。
3. 15分で採点役A・Bに、同じ5件・同じ基準・同じ出力欄を別々の文脈で渡す。他の採点役の答えは見せない。
4. 10分で、Aだけの判定と「A・Bが一致したときだけ自動確定する」判定を、人の5件の基準と比べる。
5. 5分で、不一致、同じ誤り、人へ戻す理由、追加した採点5回と確認時間を記録する。

- 不一致率は、A・Bの合否が違う件数 / 5件。
- 自動確定率は、A・Bが同じ合否になった件数 / 5件。
- 両者とも誤った率は、同じ誤判定になった件数 / 5件。Aだけの誤り率も同じ分母で出す。
- 不明・形式不備は自動確定させず、全5件に含めて件数を別記する。

練習の成功は、自動確定が3/5件以上あり、両者とも誤った件数が0/5件で、
不一致・不明の全件に人が確認すべき理由と根拠箇所を残せることとする。
Aだけでも誤りが0件なら、追加採点による誤り削減はこの試行では未確認と書く。
一致が増えても、正確さが増えたとは限らない。
二つの採点が同じ根拠を誤読していないかを見る。
追加の課金・外部送信を避ける練習では、導入済みのローカルモデルを使う。
同じモデルを2回使った場合はその条件を明記し、異なるモデル間の検証とは区別する。
