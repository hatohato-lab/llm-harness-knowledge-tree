## 1. 要点（一言と、根拠の段階と、使いどころ）

**一言：人と同じ例を採点し、ずれを調べて採点器を直す。**

根拠の段階：公式で確認。

モデル：推論型・高性能な汎用言語モデルでも、初回の校正は省かない。
軽量な汎用言語モデルは、校正後の狭い範囲から使う。
指示：良い例、悪い例、境界の例を具体的に示す。
作業：好みや専門判断を含む文章、調査の採点に向く。

## 2. 仕組み（なぜ効くか）

校正は、基準となる判定とのずれを調べて直す作業である。
採点器は、成果を採点する規則やモデルを指す。
公式記事は、人の専門判断による校正を勧める。[1]

以下は、校正を小さく始める実務案である。
不一致を読むと、モデルの誤りと基準の曖昧さを分けられる。
人同士の判定が割れる例は、人側の基準も確かめる。
モデルの点数を人が追認するだけでは校正にならない。

## 3. 使い方（手順と例）

1. 良い例、悪い例、境界の例を集める。
2. 私が、モデルの結果を見る前に採点する。
3. モデルにも同じ項目で採点させる。
4. 不一致を、根拠の読み違いと基準の違いに分ける。
5. 誤解を招いた基準や例を直す。
6. 直す際に見せていない例で、再び確かめる。

例：出典付きの誤答を、モデルだけが合格にした。
「リンクがある」と「主張を支える」を分けて書き直す。
モデル、指示、対象分野を変えたら再校正する。

## 4. 試し方（最初の一歩と測り方）

最初は50分で、短い文章の良い例5件と悪い例5件を使う。
以下の時間・件数・成功基準は、この葉の学習用の提案である。
論文の実測値や、広い仕事の性能を保証する基準ではない。

1. 10分で10件を選び、人がモデルの結果を見る前に合否と理由を書く。
2. 10分で、同じモデル・同じ設定・同じ採点項目で10件を採点する。
3. 10分で校正用6件（良3・悪3）の不一致を読み、基準か例を1か所直す。
4. 10分で、校正に見せない保留用4件（良2・悪2）を、新しい文脈で再採点する。
5. 10分で、保留用の同じ4件について変更前後の一致率と誤合格を比べる。

- 一致率は、人と一致した件数 / 4件。変更前後で分母を変えない。
- 誤合格率は、人が不合格としたのに合格にした件数 / 2件。
- 誤不合格率は、人が合格としたのに不合格にした件数 / 2件。
- 保留・形式不備は一致に数えず別記し、人の見直し時間も残す。

練習の成功は、変更後の一致が3/4件以上、誤合格が0/2件、
かつ変更前より一致件数を減らさないこととする。
変更前から同じ成績なら「維持」であり、「改善」とは書かない。
基準を直すときに保留用4件の内容や判定を参照しない。
追加の課金・外部送信を避ける練習では、導入済みのローカルモデルを使う。

合格例に偏ると、高い一致率でも欠陥を見逃せる。
安定した後も、新しい失敗例で抜き取り確認する。

κ係数は、偶然起きる一致を考慮した一致の尺度である。
例が増えたら、単純な一致率とともに確認する。[2]
二つは尺度が違い、同じ正答率として比較しない。
引き分けや保留の扱いも、同じ母集団でそろえる。
同じ答えを繰り返す安定性と、人との一致は別に測る。
κ係数が高いだけで、専門判断の正しさは保証できない。
